# Security

Do not include API tokens, private keys or production configuration in issues.
After publishing this repository, maintainers should enable GitHub private
vulnerability reporting before accepting sensitive reports. Until a private
channel exists, report dependency vulnerabilities through the relevant upstream
project's private reporting process; do not publish exploit details here.

Use only trusted artifacts. Checksums do not authenticate a publisher. Deployment
executes the supplied binary and requires root. Review changes to scripts,
workflows, plugin pins and dependencies before use. No supported-release or
security-response SLA is claimed for this initial scaffold.
